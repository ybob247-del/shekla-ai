## Skills

### Shekla Faceless Video Production

A modular skill for producing faceless YouTube and short-form videos for the Shekla AI brand. The workflow covers:

- **Strategic framing** — topic, audience, and channel direction
- **Asset intake** — logos, screenshots, voice samples, brand colors
- **Brand kit creation** — palette, typography, and visual rules
- **Script writing** — narration optimized for natural spoken delivery
- **Storyboarding** — scene-by-scene visual mapping
- **Thumbnail packaging** — clickable, on-brand thumbnail briefs
- **Short-form repurposing** — Shorts and TikTok cutdown sheets

See [`skill-shekla-faceless-video-production/SKILL.md`](./skill-shekla-faceless-video-production/SKILL.md) for full documentation.
