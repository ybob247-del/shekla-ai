# Standard Deliverables and Checkpoints

Use this reference when the skill is triggered and a faceless video-production request needs a predictable sequence of outputs.

## Core Deliverables

| Order | Deliverable | Purpose |
|---:|---|---|
| 1 | Strategy guide or positioning memo | Lock topic, audience, and channel direction |
| 2 | Competitor and packaging audit | Identify what to emulate and improve |
| 3 | Asset inventory | Confirm what is available and what is missing |
| 4 | Brand kit | Lock logo, palette, typography, and visual rules |
| 5 | Executable build package | Combine strategy, asset plan, packaging, and format decisions |
| 6 | Final narration script | Optimize for natural spoken delivery |
| 7 | Scene-by-scene storyboard | Map narration to specific visuals and motion |
| 8 | Thumbnail brief | Make packaging executable for design |
| 9 | Shorts/TikTok cutdown sheet | Reuse the master idea across short-form channels |

## Asset Intake Checklist

| Category | Required | Notes |
|---|---:|---|
| Topic confirmation | Yes | Do not start production without it |
| Voice samples | Usually | Prefer 2–3 samples if a natural voice clone or voice match is planned |
| Logo files | Yes | Transparent version preferred |
| Brand colors or live site | Yes | If no formal brand kit exists, derive one from live assets |
| Desktop screenshots | Yes | Highest priority for long-form edits |
| Mobile screenshots | No | Helpful for vertical repurposing |
| Screen recordings | No, but high value | Strongest proof for realistic product motion |
| Personal photos | No | Skip for faceless workflows unless requested |

## Hold-State Rule

If the user is still gathering assets, pause production work and switch into asset-inventory mode. Do not start the build until the user clearly says the required assets have been provided.

## Default Production Sequence

1. Confirm topic and production posture.
2. Inventory assets and identify gaps.
3. Create or confirm the brand kit.
4. Build the executable package.
5. Write the final narration script.
6. Build the storyboard.
7. Prepare thumbnail and short-form packaging.
8. Only then move into actual edit or generation work.

## Real-Not-AI Guardrails

| Area | Guardrail |
|---|---|
| Voice | Use the user's real voice or a clone derived from it whenever possible |
| Visuals | Prioritize real product screens over generic stock imagery |
| Motion | Use clean pans, zooms, crops, and callouts rather than flashy effects |
| Script | Write for speech, not for reading |
| Branding | Keep branding restrained and credible |

## Faceless Format Rules

Default to faceless if the user prefers privacy, speed, or credibility over personal-brand visibility. Avoid avatars unless the user explicitly wants them. A faceless format can still feel personal if the voice, examples, and product proof are real.
